# CLOCK IN: Solana Mobile Hackathon 2026 (with RadiantsDAO)

- **Slug:** solana-mobile-clock-in-2026
- **Organizer:** Solana Mobile + RadiantsDAO
- **Page:** solanamobile.com/hackathon (register + submit via Radiants site)
- **Dates:** Sep 8 to **Oct 8, 2026** (submissions close). Winners early Nov 2026
- **Stack:** mobile-first Android app for Seeker (Solana Mobile Stack, Mobile Wallet Adapter, Seed Vault)

## Eligibility / submission
- Functional Android APK
- GitHub repo with source
- Demo video of the app in use
- Pitch deck / short presentation
- Winners must publish on the Solana dApp Store to claim

## Judging (verbatim)
- Stickiness and product-market fit: real problem, reason for Seeker users to come back
- User experience: intuitive, polished, fun
- Innovation: fresh idea or new way to use mobile
- Presentation and demo

## Prizes
- $125k USDC: 1st $30k, 2nd $25k, 3rd $20k, 4th $15k, 5th $10k, 6th-10th $5k
- $10k SKR prize for creative, meaningful SKR integration (purchases, staking, rewards, access, new use)
- Winners: dApp Store featuring, co-marketing, Seekers, call with Anatoly
